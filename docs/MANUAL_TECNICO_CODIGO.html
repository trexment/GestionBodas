1. Arquitectura del Sistema y Flujo de Datos

El sistema sigue el patrón Single-Stack Reactive Architecture. No utiliza un frontend separado (como Vue/React standalone con API REST), sino que delega la reactividad y sincronización de estado a Livewire 3 con hydration automática del DOM mediante AJAX y WebSockets:

1. CLIENTE (Browser / Mobile)
Alpine.js • Tailwind CSS • HTML5 Canvas (Firma) • Web Audio API
2. COMPONENTES LIVEWIRE
EventShow.php • ContractSign.php • DjBoothMode.php
3. SERVICIOS & MODELOS
Eloquent ORM • DjHistoryParser • ImapLeadFetcher

3. Servicios Especializados (`app/Services`)

3.1. `DjHistoryParserService.php` (Motor de Parseo y Cruce)

Diseñado para procesar archivos heterogéneos y normalizar cadenas para comparación difusa: 

// Algoritmo de normalización y concordancia difusa
public function normalizeString(string $str): string {
    $str = mb_strtolower($str, 'UTF-8');
    $str = iconv('UTF-8', 'ASCII//TRANSLIT//IGNORE', $str); // Elimina tildes
    $str = preg_replace('/[^a-z0-9]/', '', $str);          // Elimina símbolos
    return trim($str);
}

// Cruce difuso contra las peticiones del evento
foreach ($requests as $req) {
    similar_text($normTitle, $this->normalizeString($req->title), $percent);
    if ($percent >= 80 || str_contains($normTitle, $this->normalizeString($req->title))) {
        $track['matched_request_id'] = $req->id;
        $req->update(['status' => 'played']); // Marca como sonada en directo
    }
}

3.2. `ImapLeadFetcherService.php` (Automatización de Buzones IMAP)

Se conecta vía SSL a los servidores de correo de las marcas (p. ej. Roundcube / Postfix en Plesk): 

// Conexión por socket IMAP seguro
$mailbox = '{' . $host . ':' . $port . '/imap/ssl/novalidate-cert}INBOX';
$imap = @imap_open($mailbox, $username, $password);

// Búsqueda de correos no leídos y parseo mediante expresiones regulares
$emails = imap_search($imap, 'UNSEEN');
// Extrae: Nombre de novios, Teléfono, Fecha de boda, Finca, Marca de destino

5. Seguridad, Tokens y Firma Digital Biométrica

  • Tokens Aleatorios Criptográficos: El acceso a portales públicos de novios (/guest/form/{token}) y contratos (/contrato/{token}) utiliza cadenas de 64 caracteres seguras contra ataques de fuerza bruta.
  • Certificado de Firma Electrónica: Al firmar el contrato desde el navegador móvil, el componente ContractSign.php captura:
    • Trazo vectorial en Base64 PNG dibujado sobre el canvas táctil.
    • Dirección IP pública del cliente (request()->ip()).
    • Cabecera User-Agent completa del dispositivo.
    • Timestamp UTC con milisegundos y Hash de integridad SHA-256 del documento.
